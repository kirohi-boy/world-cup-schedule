# 2026W杯 スケジュールチェッカー ⚽

2026年サッカーW杯の試合日程を日本時間でスピーディーにチェックできるWebアプリです。

🌐 **デモ：** https://kirohi-boy.github.io/world-cup-schedule/

![OGP](images/ogp.png)

---

## こんな人向け

W杯の日程と対戦カードをシンプルかつスピーディーにチェックしたい人向け

## 使い方

日程を選択するだけ

## 主な機能

- 日付ナビゲーションでその日の試合を一覧表示
- 全104試合のキックオフ時刻（JST）・対戦カード・開催地を掲載
- 各チームの注目選手・所属クラブを表示
- FIFAランキング表示（2026年4月1日時点）
- グループステージ〜決勝まで全ステージ対応

## 技術スタック

- HTML / CSS / JavaScript（バニラ）
- 外部ライブラリ・フレームワークなし
- GitHub Pages にてホスティング

## ローカルでの起動方法

```bash
# Python
python3 -m http.server 8080

# Node.js
npx serve .
```

起動後、http://localhost:8080 をブラウザで開いてください。

## データについて

- 試合日程・対戦カードは参考情報です。最新情報は [FIFA公式サイト](https://www.fifa.com) をご確認ください
- FIFAランキングは2026年4月1日時点のデータです（出典：FIFA公式サイト）
